# Catalogue of block effects

Generated by `tools/audit-block-effects.py` on 2026-11-09 from the printed oracle text of 2149 catalogue cards (`content/oracle/emperor-catalogue.json`). It is a text scan, so every row is a **candidate** to review, not a verified engine behavior; a card with more than one kind of block is listed under each. Engine state referred to below: `src/L5R.Core/Models.cs`, `MovementLocks.cs`, `EmperorRulingR1.cs`.

A **block** is an effect that stops a card or player from doing something: not moving, not straightening, not performing actions, not being targeted, not contributing Force, not bowing or being destroyed, and so on. The **Duration** column is read from the same sentence. *Until end of turn*, *This battle*, *Next time* and *Until* are the temporary blocks a player cannot see on the board today; *While* and *Persistent* are tied to a card or rule that is itself on the table. *Instant* marks a Reaction that cancels one action as it resolves and leaves no state on any card.

Only two of these reach `CardView` (`StraightenBlocked` and `ActionLocked`). Every movement lock, target shield, contribution shield, protection, Force-change block and reaction lockout lives in `MatchState` and is invisible to a client that reads only `CardView`; the player learns of it from a log line after the fact, if at all. An overlay therefore needs the engine to publish, per card, the list of active blocks (kind, source card, duration, who set it).
